# Sextile on one page

Print this page and keep it beside the keyboard. Inside Sextile, `?` shows every key.

## The screen

```text
╭─[1] Status ────────────╮╭─[0] Details ─────────────────────╮
│ your session → folder  ││ the report on the chart,         │
╰────────────────────────╯│ or the month, day by day         │
╭─[2] Chart ─────────────╮│                                  │
│ your charts, and Now   ││                                  │
╰────────────────────────╯│                                  │
╭─[3] Bodies ────────────╮│                                  │
│ the planets            ││                                  │
╰────────────────────────╯╰──────────────────────────────────╯
╭─[4] Aspects ───────────╮╭─ Log ────────────────────────────╮
│ the aspects            ││ what Sextile did for you         │
╰────────────────────────╯╰──────────────────────────────────╯
 the key bar: the keys that work where you are
```

The number in a panel's title is the key that takes you there. A small window folds panels to their title line.
There, `Enter` opens Details below the panel you are in.

## The comma key

<kbd>,</kbd> and a letter run a command. Most commands also answer to <kbd>Ctrl</kbd> and that letter.

| Press | What happens |
|---|---|
| <kbd>,</kbd> | the key bar lists the letters of the place you are in. Over a popup, it lists the popup's own |
| <kbd>,</kbd> <kbd>?</kbd> | Keybindings opens, with every key and command. <kbd>?</kbd> alone opens it too |
| <kbd>Esc</kbd> | leave. Nothing happens, and there is no time limit |

## Your first chart

| Step | Press | What happens |
|---|---|---|
| 1 | `p` | Now moves to the next Moon phase. |
| 2 | `,` `s` | Type a title and press `Enter`. The Moon phase is a chart of yours. |
| 3 | `n` | Now returns to this minute. |
| 4 | `Space`, `↓`, `Space` | Both charts are selected. |
| 5 | `4` | Aspects compares them. |
| 6 | `h` | The sky moves on by one hour. |

## Time

| Press | What it does |
|---|---|
| `y` `o` `w` `d` `h` `m` `p` | step a year, month, week, day, hour, minute, or to the next Moon phase |
| `Shift` with one of them | step back. `P` is the Moon phase before |
| `n` | now |

## Move

| Press | What it does |
|---|---|
| `↑` `↓` | move the cursor |
| `Tab` | the next panel |
| `1` `2` `3` `4` | go to a panel by its number. `0` shows the next tab of Details |
| `[` `]` | the other views of a panel |
| `Enter` | go into Details. `Esc` or `←` leaves |

## On a chart

| Press | What it does |
|---|---|
| `Space` | select it, to compare |
| `K` `J` | move it up, down |
| `Delete` | take it off the screen. The file stays. |

## Commands

A command runs after `,` and its letter, or after `Ctrl` and its letter. Every command is in Keybindings too.

| Letter | Command | Letter | Command |
|---|---|---|---|
| `o` | Open chart | `a` | Choose aspects |
| `s` | Save chart: Now as a chart | `b` | Choose bodies: the planets |
| `l` | Choose city | `x` | Wheel image: draw the wheel |
| `u` | Choose houses | `y` | Copy |
| `z` | Choose zodiac | `t` | Nodes and Lilith |

These work with the comma only.

| Press | Command |
|---|---|
| `,` `O` | Sessions |
| `,` `L` | Log. `l` there opens the log console, with the commands |
| `,` `c` `d` | Keep as defaults: city, houses, their display, zodiac and Nodes |

## In a list

| Press | What it does |
|---|---|
| type | find a row |
| `Enter` | choose the row |
| `Space` | tick a row, in a list with ticks. It shows at once. In the chart list, `Enter` opens every ticked chart |
| `Esc` | leave. Ticks stay, except in the chart list: there they go, and nothing opens |
| `Ctrl+R` | rename the row |
| `Ctrl+D` | move a saved session to the trash |

## Always

`?` every key · `Esc` back · `q` quit, or close Details
